UniSeg: A Unified Multi-modal Framework for Medical Image Segmentation

Lina Wang · Jun Li · Ming Zhou · Institute of Intelligent Medicine

Abstract

Multi-modal imaging provides complementary information for clinical segmentation. However, real-world datasets frequently contain missing modalities, causing substantial degradation in models trained under complete observations.

We introduce UniSeg, a unified framework that combines modality-aware feature fusion with uncertainty-guided regularization. The model is trained with stochastic modality dropout and requires no separate network for each missing pattern.

2. Method

Given a set of available modalities, each modality is first encoded independently. A shared fusion module then aggregates features using learned reliability estimates. During training, subsets of modalities are randomly masked.

Scholar Agent 批注：这里的随机模态遮蔽与项目当前的 modality dropout 实验直接相关，可以作为 run-007 的参数依据。

The uncertainty branch estimates voxel-level confidence and penalizes inconsistent predictions across modality subsets. This encourages stable representations when input availability changes.

3. Experiments

We evaluate the proposed method on the BraTS benchmark using Dice and Hausdorff Distance. All models are trained for 300 epochs with identical data augmentation and preprocessing.

Under the single-missing-modality setting, UniSeg retains 96.4% of the complete-modality Dice score and outperforms the strongest baseline by 2.1 percentage points.

The improvement is most pronounced when the T1ce modality is unavailable. Ablation results indicate that modality dropout contributes 1.3 points, while uncertainty regularization contributes an additional 0.8 points.

4. Limitations

The current study is limited to MRI sequences from a single benchmark. Generalization to multi-center clinical data and other imaging modalities remains unexplored.

当前研究聚焦于医学图像分割中的模态缺失问题。初步文献和实验结果支持以下研究假设：

核心假设
在训练阶段联合使用随机模态遮蔽与不确定性约束，可以减少模型对单一高信息量模态的依赖，并提高缺失模态下的稳定性。

已有证据

  • UniSeg 在单模态缺失设置下保留完整模态性能的 96.4%，其中模态 dropout 带来 1.3 Dice 提升。[Wang et al., 2025, p.4]
  • 已有方法在 T1ce 缺失时普遍出现更明显的性能下降，说明模型仍高度依赖增强肿瘤区域信息。[Chen et al., 2024, p.7]
  • 当前 run-006 的结果与文献趋势一致，但跨随机种子的方差仍需进一步验证。

下一步
