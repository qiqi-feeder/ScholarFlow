## 给 Stitch 的输入

可复制 [STITCH_PROMPT.md](STITCH_PROMPT.md)，同时提供 [前端产品需求](../../FRONTEND_PRODUCT_REQUIREMENTS.md)。视频只作为视觉参考，功能和布局以 ScholarFlow 的需求为准：左侧项目/任务导航、中央任务工作区、右侧常驻会话；对话框内有模型选择。

视频中的品牌、升级付费、日历、语音和集成等内容不代表 ScholarFlow 需要实现。输入框中的 `Select Source` 是画面上的来源入口，不能当成视频已展示模型选择的证据；模型选择属于我们另行确定的功能需求。此轮只整理参考素材，未改动应用功能。

## 文件校验

`manifest.json` 记录原视频摘要、截图时间、原帧裁切坐标、图片尺寸和文件摘要。运行仓库的 `tests/design-reference-images.tests.ps1` 可检查图片完整性、裁切边界及文档链接；这不代表已完成新前端或视觉复刻验收。
