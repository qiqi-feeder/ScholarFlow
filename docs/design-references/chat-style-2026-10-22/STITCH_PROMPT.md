# 可复制给 Stitch 的设计说明

请为 ScholarFlow 科研 AI 工作台设计桌面端原型，并补充窄屏状态。功能依据随附的《前端产品需求文档》，截图仅用于参考视觉语言。

参考截图中的明亮白色/浅灰背景、宽松留白、清晰字体层级、细边框、柔和阴影、大圆角容器、胶囊按钮、低饱和辅助图标、少量蓝色点缀，以及深色主操作按钮。优先参考 01/02 的整体层级和 03/04/05 的组件细节。不照搬品牌、英文文案或与科研无关的功能。

布局必须采用：左侧可折叠的项目/任务导航，中央根据任务显示具体研究内容，右侧始终可用的当前任务对话框。中央页面切换不隐藏会话、不新建任务。请将参考图的视觉语言应用到这个布局，不直接复制参考图以聊天首页占据全部主区域的结构。

右侧对话框需要：任务标题、状态、模型选择入口、消息记录、明确的上下文引用、多行输入、发送和停止回答。模型选择在对话框内完成；切换从下一条消息生效并保留历史；生成期间禁用，切换中和不可用时有明确状态。设置页管理凭据和默认模型。截图中未展开的菜单不作为具体菜单样式或功能依据。

请覆盖这些原型场景：

1. 完整桌面工作台：左侧导航展开/收起，中央项目或任务概览，右侧常驻会话及模型选择器展开状态。
2. 材料阅读：中央论文/PDF 与可收起的笔记/材料列表，选区加入右侧对话引用。
3. 实验与分析：中央运行列表/详情、可展开日志、指标与条件对比；待批准、运行中、失败、状态未知和未核验分别表达。
4. 写作：中央 LaTeX 编辑与 PDF 对照，展示保存、编译、版本和导出状态，右侧继续交流。
5. 审稿修订：意见清单与稿件修改对照、回应和补实验入口。
6. 必要状态：首次使用、无任务、无材料、加载、断线、无模型配置、切换失败、未保存内容及版本冲突。
7. 窄屏：工作区/对话显式切换，保留任务、草稿和状态；模型选择、发送、停止和确认可触达。

桌面优先，以 1440px 为主并检查 1024px、390px。侧边栏、阅读区和会话宽度根据内容确定，不要求三栏等宽。避免用无关仪表盘或过多卡片替代真实论文、实验数据、稿件等核心工作内容。原型中的研究数据应明确标注为示例。
