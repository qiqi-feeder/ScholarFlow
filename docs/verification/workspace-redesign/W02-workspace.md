# W02 工作现场、内容与草稿验收

日期：2026-10-22（Asia/Shanghai）。历史记录：此处为初次实施的自动回归记录，当时将 W02 全部判定通过过早。当前结论以 [视觉修正复核](W02-visual-correction.md) 为准：自动回归通过，W02 待用户视觉确认。

实现：按项目/任务保存内容标签、固定/关闭、单内容/双内容对照/列表详情、阅读位置、选中运行、视图及草稿；左侧按材料/方案/实验/结果/稿件/审稿展示真实对象。论文支持标题、当前任务/项目、可读文本状态筛选。导航可收起但保留项目/任务切换；会话宽度可调，窄屏显式切换。

稿件以源码/PDF/对照为主，文件和构建操作收纳；审稿左侧选择、中央展示所选原文与回应草稿。当前 PDF 提供原文件和页码入口，不宣称具备 OCR 或可靠 PDF 选区定位。

状态使用 schema 与 owner 校验；损坏 JSON、旧格式、跨任务载荷安全降级，存储不可用/配额不足保留内存内容并提示。稿件草稿包含基线哈希；保存时宿主进行版本比较，服务端已更新则返回 SOURCE_CONFLICT，禁止覆盖。草稿在视图/任务切换与刷新后恢复；脏文件切换/关闭提供保存、放弃、取消，刷新使用离开保护。

## 实际验证

- `npm run typecheck`：0。
- `npm test`：0，67 通过、0 失败，1 项真实模型默认跳过。
- `npm run build`：0，当前源码新构建。
- `npm run test:browser`：0，2 个 Chrome 流程通过；保留 W01 延迟/乱序/跨项目反例。
- 状态测试：重复打开不重复标签、固定对象保留、对照关闭、版本更新；拒绝损坏/旧格式/跨 owner/缺对象载荷；配额和禁用存储反例。
- 宿主集成：稿件跨项目 taskId 拒绝；正确基线可保存、旧基线 409，原新内容不被覆盖。
- 浏览器：两份真实导入文本打开/对照，打开不发送；筛选无结果；收起导航仍可切任务；A→B→A 恢复标签和页码；本地稿件刷新恢复；保存/放弃/取消关闭均操作；服务端并发改稿后旧草稿不能保存，明确放弃后才加载新正文。
- 1440、1024、390px 无页面水平溢出；截图为受控测试数据：[1440](W02-screenshots/W02-1440.png)、[1024](W02-screenshots/W02-1024.png)、[390](W02-screenshots/W02-390.png)。检查图片后将文件/构建操作收纳，避免正文编辑被文件列表挤到首屏之外。

此节点不升级科研验收，也不把后续引用、后台通知和动态能力装配记为完成。新增功能均需随节点提交保存。
