## 2. 视觉结构

原型在 1280×1024 截图中呈现的桌面结构（比例来自截图，实际实现以内容可读为准）：

- 最左图标栏约 64px；项目/任务或内容列表约 250px；中央工作区自适应；右侧会话约 360px，常驻。
- 顶部约 44px 状态条：项目/任务、运行状态、资源状态；内容标签在状态条下方。
- 浅色背景、白色卡片、细边框、低对比辅助文字、克制的蓝色主操作；圆角约 8–12px。
- 字体层级：标题 16–18px，正文 14px，辅助 11–12px；等宽字体用于代码/文件名。原型引用 Inter、JetBrains Mono 和 Material Symbols；产品实现使用现有本地 React/Vite 与系统字体栈，不引入 CDN 运行时依赖。
- 右侧会话始终显示当前任务；输入区有附件、模型入口和发送按钮。原型中的模型菜单文案只作视觉参考，真实选项必须来自 Pi。
