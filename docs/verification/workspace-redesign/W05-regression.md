## 恢复、迁移和限制

本阶段复用持久事件 JSON 保存引用与产物 ID，不增加数据库表，不删除旧事件；旧纯文本客户端继续使用 `text/clientId`。新增本地键 `scholarflow.workspace.references.v1.<projectId>.<taskId>` 与 `scholarflow.workspace.activity.v1` 带 schema/归属校验。存储损坏或不可用时安全降级并保留内存草稿；相同浏览器恢复，跨设备同步不包含在本轮。

真实重启验证发现活跃 SSE 会使 `server.close()` 等待不退出，已修复为关闭 HTTP 连接后完成停机，独立 worker 不随停止回答或关闭页面取消；新增活跃 SSE 停机回归。引用/来源打开还补齐 PDF 页码恢复及共享资产导航到可用任务。

通知只覆盖应用打开期间；首次打开建立基线，不补发离线全部历史。PDF 不承诺可靠段落选区或 OCR。AF01–AF04 的动态工具装配/输入预算/文献获取新能力仍按独立计划待设计实施，不能冒用 W 节点完成状态。

旧静态 Demo 的 `tests/workspace-light.tests.ps1` 在 W00 已记录缺失 `document.svg`，本轮不修改该历史 Demo，也不宣称全仓所有历史测试通过。`latexmk` 缺 Perl 的既有问题保留，当前构建实际使用可用的 `pdflatex/bibtex`。
