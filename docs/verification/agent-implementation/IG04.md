memoryAt 区分有效时间与系统获知时间。来源纠错在获知后适用于其原有效期间；state_change 显式给有效起点，早期查询保留旧状态；撤回只在 knownAt 已知时影响召回。没有时间的记录保留 validityUnknown，不猜造发生时间。晚到且已结束的事实不进入当前查询。

召回先鉴权项目/任务，再做 subject/predicate 精确或文本相关性过滤。争议命中扩展至双方，按整个冲突组计入预算，放不下时给排除原因；候选不注入正式上下文。共享项目记忆可跨任务；私有任务记忆、按 ID/版本读取、召回快照和写入沿用范围校验，无跨任务缓存。SQLite 版本记录是事实来源，未引入向量服务。
