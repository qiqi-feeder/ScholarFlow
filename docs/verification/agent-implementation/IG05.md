Experience 保存 cue、lesson、适用条件、证据记忆精确版本、来源任务及方法版本。仅 active 且无争议的证据可提炼，先 candidate，经用户核验才 validated；源证据改变后要求重新核验。不把模型 confidence 当证据，不隐式跨项目共享。
