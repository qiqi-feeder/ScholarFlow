# IG03 来源记忆与冲突事务

日期：2026-10-26。对应提交：`git log --grep="IG03"`。数据库 schema v2，沿用 IG00 升级备份与事务恢复，旧材料没有自动提升为事实。

领域类型记录来源身份、项目/任务范围、subject/predicate、条件、版本、有效时间与获知时间。宿主只从本任务已保存事件映射：用户/助手聊天为候选；确认方案核对真实用户批准；工具观察/材料保留各自身份。Agent 不能确认或改写事实，也不能提供未经核实的有效时间；未知时间留空。

memory_versions 保存所有版本，heads 为派生当前指针，changes 含前后版本及理由，ingestions 按来源事件/对象/条件幂等。修订 expectedRevision 冲突返回 409；记录、冲突双方版本、审计和事件同事务落盘后才通知。跨项目和任务私有规则适用于读取、按 ID、历史、修订、去重与写前查询。现有 SQLite 索引可从版本记录重建。

同条件矛盾保留双方 disputed；不同条件并存；助手候选不覆盖确认决定。用户确认/更正保留独立 memory_reviewed 事件，原论文与工具观察只允许撤回或另记决定，不能修改原始指标。撤回/更正更新争议关联，通知既有引用需核对，原始文件保持。

RT07/RT08：事件重试不重复、来源角色、跨项目所有路径、任务私有、候选不能自升格、不同条件并存、双向争议、乐观并发、未知/非法时间及故障注入事务回滚。出口 `npm run verify`、`node --test tests/*.test.mjs`、`git diff --check`。历史召回与 UI 在 IG04 验证。
