# IG01 动态能力

日期：2026-10-26。对应提交：`git log --grep="IG01"`。复用锁定 Pi 的 ExtensionAPI 注册、setActiveTools/getActiveTools 与 model_select；没有新增运行时依赖。

基础集合为发现、加载、卸载、研究恢复、Skill 目录、运行查询/取消和文件读取。首批分组为 literature/planning/analysis/writing。目录含 Skill 哈希、版本、依赖与失败原因。所有领域工具先注册，加载正文后校验 Pi 的实际活动集合；未知或被忽略工具视为失败，恢复原集合。卸载保留恢复/取消工具。工具调用另检查任务活动集合，领域服务保留原准入、批准与预算检查。

每任务控制器独立；发送期间的能力调用在该任务的同一 Pi 循环中同步完成，外部发送/切模型仍使用任务互斥。停止与配置竞争会返回 busy；切模型清空已加载集合，重开也从基础集合开始，不将历史激活视为授权。读取 Skill 再核对任务归属及当前依赖。

RT03/RT04、AT01–AT04 的确定性验证：真实 Pi SDK + 本地受控模型端点执行 load_skill，同消息第二次模型请求已含分析工具及方法正文；重开恢复基础工具。测试另验证失败回滚、未知能力、缺依赖、任务范围、卸载保留核心，既有发送/切模型忙碌回归保持。受控端点不作为真实 API 成效。

阶段出口：`npm run verify`、`node --test tests/*.test.mjs`、`git diff --check`。真实外部模型与机制效果留 IG07。
