# IG06 独立评测、发布与回退

日期：2026-10-26。对应提交：`git log --grep="IG06"`。

固定协议使用 IG00 的开发/留出目标，并增设单独最终回归（目标实验审批与 smoke 诚实性）。每张卡分别新建 Pi 会话执行基线与候选，模型/温度/材料/权限/输出上限相同，无工具、无目标训练。每次完整评测 12 请求，程序校验 JSON 和事实，不接受自评分；候选六卡全过且无基线退化才 validated。开发反馈可见，留出与最终集只返回总数，逐样本轨迹保存在宿主表，候选工具无读取入口。

所有尝试包括失败、取消与中断均持久化；先记请求意图再调用，保留实际模型、usage、延迟与失败。每候选至多两次尝试，且同一正式基线修订总共至多两轮，避免无限换候选重复适应留出集。候选总请求/输出/时长限额沿用 IG05；超预算不自动扩额。重启将 running 标记 interrupted、保留消耗，不自动继续。

发布须用户确认精确候选哈希及评测、baseline hash/head revision，重新核对来源仍有效；事务内 compare-and-swap 正式指针和审计，失败原指针保持。回退新增记录，旧任务继续使用绑定版本；主动迁移须用户确认，任务忙碌拒绝，迁移清除加载会话以便下次核对能力。

RT13/RT14：确定性执行器覆盖基线参加、开发/留出/最终隔离、全部失败尝试与取消、预算、确认拒绝、指针故障注入回滚、并发/ABA 防护、回退与旧任务绑定、显式迁移、重启中断恢复。另用真实 Pi SDK + 本地受控端点验证隔离评测没有工具、确实收到对应方法与输出上限；浏览器覆盖评测、确认发布和回退。受控输出验证状态机，不声明方法真实收益；外部真实推理结果由 IG07 单列。

出口：`npm run verify`、`npm run test:browser`、`node --test tests/*.test.mjs`、`git diff --check`。正式发布默认关闭自动行为，未自动发布真实用户项目方法。
