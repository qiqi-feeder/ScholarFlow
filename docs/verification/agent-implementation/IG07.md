## RT15 固定卡与机制消融

[固定卡](evaluation-cards.json) 在 IG00 固定，分组 baseline/capabilities/bounded-context/memory/evolved-method；[机制比较](mechanism-ablation.json) 记录相同模型、权限、任务夹具、次数及输入/输出预算，并拒绝不一致条件的配对。

工具定义从全量 30 个到基础 15 个；固定长日志输入由约 312825 降至 16390 估算 token，保持原用户约束与重新查询入口。它们是确定性软件开销/约束比较，**不是模型质量或科研实效分数**。时间、矛盾与范围消融的行为证据由 memory.test.ts 与输入预算测试验证；新方法的真实生成比较独立记录，不能把旧轨迹回放当作新方法效果。

## 本阶段补强与界面

共同输入估算使用实际 usage（含缓存输入）校准，仍标估算且不放宽保守边界。现实状态改变追加关闭旧有效区间的版本；来源纠错继续保留历史。保存回包不会关闭仍有新编辑的稿件，也不会切回已离开的文件。补充 URL 下载地址校验和 DNS 固定，拒绝经本地 HTTP 接口绕过项目归属，逐跳检查重定向；模型仍无宿主 shell/write/edit 工具。

已检查新记忆/方法表单在 [1440px](browser/memory-methods-1440.png) 和 [390px](browser/memory-methods-390.png) 的截图与交互，输入有独立标签，页面无横向溢出，沿用既有工作台风格。

## 边界

当前仍为单用户本地应用，文件夹不是操作系统沙箱。数据库升级先备份、事务迁移，恢复到新路径；旧 Pi 会话和研究数据不自动发送、执行或发布。候选预算与失败尝试保留，发布和回退需要用户在产品中确认具体版本，旧任务主动迁移才更新。
